# Project Mission

Mission: jawelte
jawelte is a Jakarta-based Java test framework that makes integration testing as simple as writing a JUnit test.
Built with Jakarta, not just for it: CDI beans and events form its backbone, MicroProfile Config drives its configuration. On top of this solid foundation, jawelte provides a pluggable integration layer with first-class support for JPA/JTA, JAX-RS, MicroProfile, DB-Unit, H2, Mockito and WireMock. Each integration is opt-in, every default is meaningful, the API is minimal, and a powerful SPI allows deep customization.
Quality is non-negotiable: jawelte is exhaustively self-tested, thoroughly documented, fast by design, and as reliable as the platform it builds on.
Simple to use. Minimal by design. Pluggable at heart. Solid to the core.
