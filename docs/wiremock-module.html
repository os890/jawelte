wiremock-module wraps WireMock's stub server in a CDI lifecycle so you can @Inject WireMockServer and @Inject WireMock directly into a test. @EnableWireMock on the test class boots one server per declared endpoint, resets the stubs between methods, and tears the servers down in afterAll. Multi-endpoint tests get one CDI qualifier per upstream — type-safe and compile-time-checked.

1. quick-start

1.1 purpose

The standard WireMock setup — build a WireMockServer, start it in @BeforeAll, stop it in @AfterAll, reset stubs in @BeforeEach, propagate the port to the system under test — is the same scaffolding every time. wiremock-module collapses it into one annotation: @EnableWireMock handles the lifecycle, a CDI producer injects the server / stub-registration client, the lifecycle adapter resets stubs between test methods.

1.2 hello-world

One annotation on the test class, two @Inject fields, a real HTTP round-trip in the test body.

listing wiremock-module/01 · hello-worldlistings/wiremock-module/01-hello-world/
// src/test/java/example/wiremock/HelloWireMockTest.java
@EnableWireMock
class HelloWireMockTest {

    @Inject
    WireMockServer server;

    @Inject
    WireMock stubs;

    @Test
    void getReturnsStubbedBody() throws Exception {
        stubs.register(get(urlEqualTo("/hello"))
                .willReturn(aResponse().withStatus(200).withBody("hi")));

        HttpResponse<String> response;
        try (HttpClient client = HttpClient.newHttpClient()) {
            HttpRequest request = HttpRequest.newBuilder()
                    .uri(URI.create(server.baseUrl() + "/hello"))
                    .GET()
                    .build();
            response = client.send(request, HttpResponse.BodyHandlers.ofString());
        }

        assertThat(response.statusCode()).isEqualTo(200);
        assertThat(response.body()).isEqualTo("hi");
    }
}

@EnableWireMock is meta-annotated @EnableTestBeans, so the test class doesn't need to write both annotations. The default OS-assigned port comes from the implicit no-qualifier endpoint.

1.3 maven setup

wiremock-module's api / impl plus the standard CDI runtime (cdi-module + scope-module). The WireMock library itself is brought in transitively via jawelte-wiremock-module-impl — no need to add the upstream dep yourself.

2. detailed

2.1 @EnableWireMock

@EnableWireMock is a class-level marker with no attributes. Endpoint configuration (port, qualifier) lives on the @WireMockEndpoint meta-qualifier — not on the activator. The annotation is meta-annotated with @Inherited, so a test class that extends a base class carrying @EnableWireMock picks up the activation automatically.

The lifecycle hook runs at JUnit Jupiter @Priority(75) — same band as jaxrs-module, between testcontrol-module (50) and scope-module (100). It reads the annotation off the test class in beforeAll, boots one WireMockServer per discovered @WireMockEndpoint qualifier (or a single default server when no qualifier was found), and shuts them down in afterAll.

2.2 @WireMockEndpoint — per-endpoint qualifiers

Multi-upstream tests declare one user @Qualifier annotation per endpoint, each meta-annotated @WireMockEndpoint:

@WireMockEndpoint(port = 0)
@Qualifier
@Retention(RUNTIME)
@Target({FIELD, METHOD, PARAMETER, TYPE})
public @interface PaymentApi { }

@WireMockEndpoint(port = 0)
@Qualifier
@Retention(RUNTIME)
@Target({FIELD, METHOD, PARAMETER, TYPE})
public @interface InventoryApi { }

The qualifier doubles as the lookup key: @Inject @PaymentApi WireMockServer paymentServer, @Inject @InventoryApi WireMock inventoryStubs. Endpoint identity is a compile-time CDI qualifier, not a string name — typos are caught by the compiler.

port = 0 — OS-assigned ephemeral port (recommended; no port-conflict flakiness when multiple suites run on the same host). The resolved port is then readable via server.port().
port = N (N > 0) — bind to a specific port. If already in use, beforeAll fails with a BindException.

2.3 @Priority — the implicit default

In multi-endpoint mode, an unqualified @Inject WireMockServer is ambiguous by default. Add @jakarta.annotation.Priority to one of the qualifiers and that qualifier's server becomes the implicit default:

@WireMockEndpoint(port = 0)
@jakarta.annotation.Priority(1)        // lowest value wins
@Qualifier @Retention(RUNTIME) @Target({FIELD, ...})
public @interface PaymentApi {}

@WireMockEndpoint(port = 0)
@Qualifier @Retention(RUNTIME) @Target({FIELD, ...})
public @interface InventoryApi {}

@EnableWireMock
class MyTest {
    @Inject WireMockServer server;             // → @PaymentApi (lowest priority)
    @Inject @PaymentApi   WireMockServer p;
    @Inject @InventoryApi WireMockServer i;
}

Without @Priority — or with a tie on the lowest value — every synthetic bean keeps @Default, and unqualified injection raises the standard CDI AmbiguousResolutionException at deployment.

2.4 stubs reset between methods

The lifecycle adapter calls WireMockServer.resetAll() in its beforeEach, so stubs you register in one method don't leak into the next. This is independent of CDI scope destruction — even if testcontrol-module vetoes scopes for a method, stubs are still reset.

3. spi / port reference

wiremock-module ships no SPI / port of its own. The api jar contains exactly two annotations: @EnableWireMock and @WireMockEndpoint. Customization happens through:

  • Endpoint configuration — declare additional @WireMockEndpoint-meta-annotated qualifiers; the CDI extension picks them up at BeforeBeanDiscovery.
  • WireMock library settings — whatever WireMockConfiguration exposes is reachable through the injected WireMockServer handle. For deeper configuration (HTTPS, file-based mappings, listeners), inject the server and call its configuration API directly before the first request.
  • Scope handling — wiremock-module ships a BeanScopeMapper provider that remaps WireMock's registry markers to @TestClassScoped. See scope-module's SPI section for how to write additional mappers.

There's no MP Config key wiremock-module reads directly. Port-pinning lives on the @WireMockEndpoint(port = ...) attribute, which is compile-time typed.
